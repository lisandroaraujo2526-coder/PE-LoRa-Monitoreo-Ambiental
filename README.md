# PE-LoRa-Monitoreo-Ambiental

Repositorio del proyecto final de monitoreo ambiental mediante LoRa.

## Estructura

- `Nodo_Transmisor/`: firmware del nodo transmisor para Heltec ESP32-S3.
- `Gateway_Receptor/`: recepción de datos LoRa y comunicación con MQTT.
- `Servidor/`: servicios en Python, integración MQTT y almacenamiento en InfluxDB.
- `Documentacion/`: diagramas, instrucciones y documentación del proyecto.

Cada directorio incluye una guía inicial para organizar sus archivos. La implementación y los parámetros específicos se agregarán conforme avance el desarrollo.
