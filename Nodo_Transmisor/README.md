# Nodo transmisor

Firmware principal: [`Nodo_Transmisor.ino`](Nodo_Transmisor.ino).

Desarrollado para la placa Heltec WiFi LoRa 32 V3 (ESP32-S3 y SX1262), con sensores YYS SC401 y SONOFF THS01. Utiliza las bibliotecas Arduino RadioLib y U8g2.

El spreading factor LoRa configurado para el proyecto es SF9.
